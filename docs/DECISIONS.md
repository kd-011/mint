# Mint: decisions

A dated record of why Mint is built the way it is, newest first. Entries are records of intent, not claims about the code, so this file is not pinned. New decisions go here, each with its date and a reason. A decision that is overtaken stays and is marked `Superseded <date>: <what replaced it>.`

- 2026-11-03: Local mode runs the real server on a random inner port behind a loopback-only front, with the fingerprint lock off and a fresh gate key each run (`scripts/local.mjs`, `lib/localfront.mjs`). Why: a stranger can try Mint on one machine with no login proxy, and the front answers only to `127.0.0.1`, `localhost` or `[::1]`, so a DNS-rebound or cross-site request is refused.
- 2026-11-03: One timezone per install, `MINT_TZ`, default Australia/Perth, and `lib/dates.mjs` is the only module that names a zone (`test/tz-guard.test.mjs` enforces it). Why: days, pay cycles, the financial year and the nightly run must agree, and daylight saving then needs no special case elsewhere. Changing it later does not rewrite stored dates.
- 2026-11-01: `REDBARK_API_KEY` is optional. Why: Redbark is a paid service, and Mint should be usable without one, so manual accounts and CSV import are a first-class path and the page hides every Redbark prompt when the key is unset.
- 2026-11-01: Mint goes open source under AGPL-3.0. The public repository is a series of export commits of this tree (`scripts/export-public.mjs`), never this repository's history, which holds screenshots and figures from a real book. Why: this repository's history holds screenshots and figures from a real book, and the export's denylist, scan and image gate are the guard.
- 2026-10-26: The phone-first UI kit pass was redone keeping Mint's own palette, green gradient net worth hero, tracked-caps labels, glass dock and pill controls, with the kit supplying Geist, phone type roles, toasts and sheet motion. The first attempt, which took the kit's look whole (flat grey hero, tinted controls), was reverted. Why: the owner judged the first attempt greyer and more generic than Mint's own identity.
- 2026-10-17: A webhook delivery triggers an API re-read instead of inserting rows. Why: webhook and v2 transaction ids are not documented as the same value, so rows are always read back through the v2 API to keep one source of ids.
- 2026-10-17: Loans and cards keep Redbark's negative balances, and net worth is the plain sum of account balances.
- 2026-10-17: No npm dependencies: `node:http`, `node:sqlite` and a vanilla single page app. Why: the project is deliberately small, one user with no build step, and the book stays one file the owner can copy.
- 2026-10-17: The original product decisions (scope, categorising approach, budgets, tax) were settled in the owner's planning notes outside this repo and are not repeated here.
